# W-Team_Gym-Membership
The Gym Membership Management System is a digital platform designed to streamline and automate gym operations by replacing manual record-keeping with structured GUI forms, reliable role-based user management, and seamless navigation. Built around an abstract 'User' base class, the system enforces access control and tailored functionality across 'Member', 'Trainer', and 'Admin' roles. Members can manage their profiles, select or renew 'MembershipPlan' options, handle 'Payment' tracking, and book training sessions. Trainers can schedule training 'Session' slots and monitor attendance, while Administrators maintain oversight over member accounts, session schedules, membership plans, and overall operational payments. To ensure data integrity, user safety, and smooth operation, the application integrates 'JOptionPane' error handling to display clear feedback and validation messages whenever invalid input or system errors occur.
